# NegPy 用户指南

NegPy 通过虚拟暗房将胶片扫描制作为正像。源图像保持原样，编辑保存在本地数据库。界面语言在偏好设置的“语言”中选择，重启后生效。支持英文、简体中文、日文、韩文和跟随系统，其他系统语言使用英文。

## 工作流程

载入胶卷后，选择胶片模式与扫描装置，校正光源和镜头，裁切画面并分析胶卷，再调整单帧密度、反差、滤色与修复，最后导出。卡片标题的画面／胶卷按钮控制应用范围，恢复胶卷设置可拉回共享值。单帧裁切位置与旋转保留在画面上。

## 胶片条

画布下方的**胶片条**把打开的帧排成一行。拖动其上边缘可放大帧。

工具栏的**胶卷**一行包含：

- 胶卷名称，以及帧数、保留数和拒绝数。
- **筛选框**：输入文件名的一部分，或 `film:portra iso:>=400` 这样的条件（见下）。搜索按钮或 **Enter** 会搜索整个图库。
- **排序**：按名称、日期或场景。
- **画面筛选**：所有画面、仅保留画面、隐藏拒绝画面或仅未标记画面。筛选隐藏画面时，按钮会高亮。
- **胶卷设置**（标签图标）：此帧、所选帧或整卷的器材和胶片信息。
- **应用**：把此帧选定的设置复制到所选帧或整卷。
- **⋮**：**添加文件…**、**添加文件夹…**、**另存为胶卷…**、**更新缩略图**、**监视文件夹**（扫描仪保存新文件时自动载入）、**卸载…**、**新建胶卷…**、**关闭胶卷…**、**将胶卷恢复为默认值…**和**胶片条指南…**。

右键点击某帧可将其**保留**（对勾）或**拒绝**（叉号；批量导出会跳过）。

网格按钮打开**灯箱**（`Shift+G`）：整卷分多行排列，便于挑选。单击选择帧，双击或按 `Enter` 打开。工具栏作用于所选画面：**保留**、**拒绝**、旋转与翻转、**自动裁切**和**导出**，⋯ 中是右键菜单的其余操作。它的**每行帧数**滑块、`+` 和 `-`，或按住 `Ctrl` 滚动滚轮，可改变帧的大小。`Esc` 返回。

### 筛选

单词匹配文件名。`field:value` 条件匹配帧信息，前面加 `-` 表示排除：

| 条件 | 查找 |
|---|---|
| `film:portra` | 胶片名含“portra” |
| `camera:"Nikon F3"` | 含空格的值用引号括起 |
| `iso:>=400` | 数字还可用 `>`、`>=`、`<`、`<=` |
| `date:2024-03` · `shot:>=1998` | 文件日期 · 拍摄日期 |
| `place:tokyo` · `lens:` · `roll:` | 其他元数据字段 |
| `scene:beach` | 场景中的帧 |
| `keeper:` · `rejected:` · `edited:` | 已标记或已编辑的帧 |

条件可以组合：`film:portra iso:>=400 -rejected:`。元数据条件只匹配填写过元数据的帧。**语义搜索**（在偏好设置 → 性能中开启）可用描述找照片，如“海滩上的狗”。

## 图库

**图库**选项卡（`Ctrl+L`）列出你的**胶卷**。胶卷是一组命名的帧，通常是一卷胶片。导入只记录文件夹；NegPy 从不移动、重命名或删除你的文件。

- **+**：**将文件夹导入为胶卷…**把一个文件夹作为一卷并打开。**将子文件夹导入为胶卷…**为每个含图像的子文件夹各建一卷。
- **双击**胶卷（或按 Enter）在胶片条中打开。
- **⋮** 或右键点击胶卷：**打开**、**关闭胶卷…**、**胶卷分析**、**重命名…**和**删除…**。删除只会忘记该卷，文件和编辑都保留。
- **筛选胶卷…**和排序帮助你找到胶卷。**⋮ → 刷新**查找新的子文件夹并重新统计帧数。**⋮ → 发现筛选…**列出要跳过的文件夹名（初始为 `export`）。

文件夹已不存在的胶卷会显示**文件夹缺失**。与你的器材匹配的文件夹名（如“penf”对应“Pen F”）会打开已填好的胶卷设置。

胶卷也可以是任意一组帧：搜索或收集后，在胶片条中**另存为胶卷…**。一帧在包含它的所有胶卷中共用一份编辑；右键 → **在此胶卷中独立编辑**可让它在某一卷中有自己的编辑。

**HE** 或 **HE\*** 压缩的 Nikon Z 8 和 Z 9 NEF 无法打开。请使用**无损压缩**拍摄，或用 Adobe DNG Converter 转换。

## 分析读数

卷和帧选项卡上方的分析读数在编辑时描述当前帧。

### 图表

图表上方的按钮选择视图：

- **曲线**：相纸曲线，从左到右是负片，从下到上是照片。越陡反差越大。灰色直方图是负片，彩色直方图是照片。
- **波形图**：整幅画面的照片亮度。
- **并列图**：并排显示红、绿、蓝；灰色主体在三者中高度一致。**并列图叠加**把三者画在同一张图上。
- **矢量示波器**：把照片颜色画在中心点周围。偏离中心的一团表示色偏。

**Log** 显示小面积区域，如截断的两端。

### 截断

上方角落的三角形在暗部变成纯黑（左）或高光变成纯白（右）时发出警告。**截断叠加**（半圆按钮）在画面上标出这些部分。**区域高亮**（马克笔按钮）在画面上只显示光标下的区域。

### 区域与区域定位

**阶梯灰板**显示 21 级灰；融入黑或白的级数就是丢失的色调。**区域条**显示画面落在从 0（黑）经 V（中灰）到 X（白）各区域中的比例。双击它（或按 `Shift+Z`）打开**区域叠加**，按区域给画面着色。

在区域条上点击一个区域，再点击画面上的一点，NegPy 会让该点印在那个区域。一个定位点设置印相密度；第二个还会设置 ISO-R 反差等级。**放置区域**（或 Enter）应用结果，`Esc` 取消。

### 读数

**读数**折叠区中有关于扫描的数值。琥珀色的值是警告；把指针停在某行上可查看详情。

- **负片**：负片的密度范围 (Δ)。悬停可查看属于平淡、正常还是强烈。
- **曝光**：画面偏亮（正）或偏暗（负），以挡表示。
- **截断**：照片中纯黑、再纯白的比例。
- **扫描截断**：红、绿、蓝各通道达到扫描仪最大值的比例。编辑无法修正，请降低扫描曝光。
- **修复**：除尘改写的比例。
- **色域**：软打样时校样打印机无法印出的比例。

## 裁切

手动或用自动裁切，选择要保留的画面部分。

- **绘制**：在画面上拖出裁切范围。拖动角点调整大小，拖动内部移动，在框外拖动旋转。**×** 清除你绘制的裁切。绘制会关闭自动裁切。
- **自动裁切**：找到画面边缘并按其裁切。
- **比例**：裁切形状，如 `3:2` 或 `1:1`，会按画面转向。**自由**使用 NegPy 找到的形状，并可单独拖动一条边。**检测**选择最接近的标准形状。
- **参考线**：绘制时显示的三分法等构图线。旋转按钮可改变方向。
- **模式**（自动裁切设置折叠区）：**仅图像**只裁到画面。**胶片边缘**保留带边框和齿孔的整幅胶片。
- **裁切偏移**和**片边修剪**（模式下的折叠区）：把裁切移到找到的边缘内侧（正）或外侧（负），并设置裁切切入胶片边框的程度（仅图像）。0% 停在胶片边缘，100% 停在画面边缘；超过 100% 会切入画面以去除白边。
- **先摆正**：自动裁切前先按胶片边缘把画面摆正。
- **裁切所有画面**（仅图像）：一起裁切所有帧。清晰的帧帮助不清晰的帧，你手动画的裁切保持不变。

自动裁切要求扫描仪光源或片夹是扫描中最亮的部分。当画面和光源一样亮，或相邻帧占据一边的大部分时，它不会裁切该帧。请手动裁切，或使用**胶片边缘**再向内修剪。

## 拉直

旋转画面并把它摆正。

- **旋转**和**翻转**：把画面转 90°，或镜像翻转。工具栏上也有相同的按钮。
- **水平校正**：沿地平线或竖直边缘画一条线，画面随之旋转摆正。
- **对齐胶片**：让画面与胶片边缘对齐。它不看画面内容，所以有意斜拍的照片仍保持倾斜。
- **精细旋转**：小幅旋转画面。正值为顺时针。
- **俯仰**和**摆动**（折叠区）：校正从下往上拍的建筑（俯仰）或从侧面拍的墙（摆动）。**绘制参考线**根据沿胶片四边画的线同时设置两者。
- **裁掉空白角**：裁掉旋转、俯仰和摆动留下的空白角。

在大幅俯仰或摆动之前先裁切，否则胶片边框可能进入画面，使照片变暗。镜头畸变在卷选项卡的**光学**中校正。

## 滤色：色彩平衡

像放大机的彩色滤镜一样校正照片的颜色。**全局 / 暗部 / 高光**把颜色调整用于整个画面，或主要用于暗部或亮部。

- **白平衡吸管**：点击画面中本应是灰色的地方，颜色会被校正使其变灰。
- **色温**：让画面偏暖或偏冷。
- **青 / 品红 / 黄**：在青色与红色、品红与绿色、黄色与蓝色之间偏移颜色。
- **环绕试样**（`Shift+F`）：以网格显示颜色略有不同的多个版本。点击看起来正确的那一格。`Esc` 关闭。
- **去色偏**：去除画面暗部与亮部不同的色偏。彩色负片从 1（完全）开始，反转片从 0 开始。树叶、天空和水不算作灰色，因此保持原有颜色。

## 色调：亮度与反差

照片的明暗程度和反差大小。

- **印相密度**：照片的明暗（暗房中的曝光时间）。数值越低越亮。
- **ISO-R 反差等级**：反差（暗房中的相纸号数）。数值越低反差越大，约 110 为常规。
- **自动**：**自动密度**和**自动反差**为每帧设置亮度和反差，让整卷印出来一致。滑块显示自动值：拖动即在此基础上调整，双击则恢复。自动菜单还包含：
    - **设置目标…**：自动功能追求的亮度和反差。
    - **固化自动密度／反差**：保存此帧的自动值，并关闭此帧的自动功能。
    - **保持黑点**：提亮暗部时，最深的黑仍保持黑色。
- **试条**（`Shift+T`）：不同亮度和反差的网格版本。点击你喜欢的那一格。`Esc` 关闭。
- **暗部密度** / **高光密度**（印相密度下方的折叠区）：只加深或提亮暗部或高光。
- **暗部反差** / **高光反差**（ISO-R 反差等级下方的折叠区）：只调整暗部或高光的反差。
- **印相辅助**（折叠区）：
    - **预闪**：找回最亮区域的细节。
    - **柔光**：柔和的光晕，暗部向亮部扩散。
    - **反差蒙版**：降低整体反差并保留细节。负值则增加反差。**蒙版间距**决定蒙版的柔和程度。
- **全局 / R / G / B**：R、G、B 只把反差调整用于一种颜色，用于暗部和高光色偏不同的情况。

**白点**和**黑点**位于卷选项卡的**测光**卡片中。

## 相纸响应：相纸

照片所印的相纸，以及相纸如何把光变成从黑到白的色调。

- **印相材料**：相纸。真实相纸根据厂商数据决定反差曲线和颜色。默认的**数字 (Adobe RGB)** 是理想相纸。**数字 (Pakon Minilab)** 呈现 Pakon 冲印扫描仪的颜色。
- **相纸试条**（条纹按钮）：把此帧印在每种相纸上。点击某种相纸放大查看，用方向键切换，按**保留**使用它。
- **染料分离**：照片的色彩浓度。1 为不变。**分离抑制**让变化更多作用于暗淡颜色，较少作用于鲜艳颜色。风格选项卡中的**色度**则均匀改变所有颜色。
- **相纸白**：显示真实相纸的白色，比纯白略暗。
- **相纸黑**：显示真实相纸的黑色，比纯黑略浅。
- **曲线形状**（折叠区）：
    - **中调力度**：中间调反差。黑和白不变。
    - **趾部**：调整暗部形态。正值提亮，负值加深。**趾部宽度**决定其延伸到中间调的范围。
    - **肩部**：调整高光形态。正值使其柔和，负值使其更亮但可能丢失细节。**肩部宽度**决定其延伸范围。
- **全局 / R / G / B**：R、G、B 只把曲线调整用于一个颜色层。

## 局部加减光：让局部变亮或变暗

画出一个形状，只让该区域变亮（减光）或变暗（加光）。反转片不使用此卡片，但其蒙版会保留。

- **绘制**：点击放置节点。双击、按 Enter 或在起点附近点击即可闭合形状。拖动节点可移动，点击边上的“+”可添加节点，右键点击节点可删除。
- **椭圆**：拖出一个椭圆。用控制点移动、拉伸和旋转它。
- **卡片**：渐弱的加光，就像在相纸上移动一张卡片。从最强的边缘（实线）拖到效果结束的位置（虚线）。
- **蒙版列表**：点击蒙版将其选中。用图标开关它、反转（作用于内部以外的区域）、显示轮廓或删除。下方的滑块调整所选蒙版。
- **加光**：正值变暗，负值变亮。单位为挡：+1 使光量加倍。
- **羽化**：边缘的柔和程度。
- **反差等级**：蒙版内的反差。负值反差更大。
- **闪光**：像预闪一样，找回蒙版内亮部的细节。
- **色调限制**：选择**高光**或**暗部**后，蒙版只作用于比**色调区域**（0 为黑，V 为中灰，X 为白）更亮或更暗的色调。天空加光会停在天际线处。**色调柔化**决定效果开始时的渐变程度。

**印相笔记**（`Shift+N`）像印相师的笔记一样，在画面上用编号和数值标出各个蒙版。

## Lab：色彩与细节

冲印扫描仪在印相之后做的调整。

- **色度**：色彩浓度。1 为不变，0 为黑白。
- **肤色保护**：防止肤色过于浓艳。
- **色度降噪**：去除彩色噪点，保留胶片颗粒。
- **锐化**：锐化细节且不产生彩边。折叠区中有**方法**（非锐化蒙版让边缘更清晰，反卷积还原扫描仪造成的模糊）、**半径**（细节大小，单位为像素，请在 100% 缩放下判断）和**蒙版**（只锐化边缘，让天空和皮肤保持平滑）。
- **CLAHE**：局部反差，用于突出细节。数值过高会显得不自然。
- **辉光**（效果折叠区）：像老镜头一样在亮部周围产生柔和光晕。
- **光晕**（效果折叠区）：部分胶片在亮部周围出现的红色光晕。

## 替代工艺

用于黑白负片的传统印相工艺。选择**无**、**丽斯**、**蓝晒**或**萨巴蒂尔**后，只显示该工艺的控件。

### 丽斯

奶油般温暖的高光和浓重的深黑。颜色由相纸响应中的印相材料决定。丽斯照片只有硒和金调色有效。

- **曝光**：越多高光越暖、越有色彩，影调越柔和。
- **取出时机**：相纸离开显影液的时机。越高黑色越深越冷。
- **突变程度**：暗部变黑的突然程度。

### 蓝晒

带绿色高光的蓝色照片。调色对它无效，请使用漂白和单宁。

- **感光剂**：**经典**呈浅蓝并带绿色高光，**新配方**的蓝色更深更纯。
- **曝光**：越多越蓝。
- **曝光跨度**：反差。跨度越短反差越大。
- **漂白**：从高光开始褪去蓝色。
- **单宁**：把漂白区域变成棕色。要整体棕色，请先漂白。

### 萨巴蒂尔

显影中途的一次闪光。亮部色调向灰色反转，并在明暗交界处出现细亮线（马基线）。

- **强度**：闪光的时长。超过 1 时亮部反转。
- **再曝光**：反转开始的位置。更暗的色调保持不变。
- **搅动**：搅动越少，马基线越宽。

## 调色

调色是改变黑白照片颜色的化学药浴。分离色调可为任何照片加色。

**化学调色**（黑白负片）按显示的顺序进行：

- **硒**：更深、更冷的黑色。
- **棕褐**：从高光开始呈温暖的棕色。
- **金**：蓝黑色。叠加在棕褐上时高光呈橙红色。
- **铁蓝**：蓝色暗部和深蓝黑。
- **铜**：粉红到砖红色，黑色变浅。
- **钒**：中间调和高光呈绿色，黑色保持不变。

丽斯照片只有硒和金有效。蓝晒照片上任何调色都无效。

**分离色调**（所有照片）：**暗部强度**和**高光强度**为暗部和高光加色。**暗部色相**和**高光色相**选择颜色，在强度大于 0 时显示。

## 漏光

在任何除尘修复之前，只在你放置的漏光形状下减弱漏光加在负片或反转片上的光晕。烧透的胶片会保留：请修复或仿制。正片帧和合成画面上不可用。

- 减弱漏光开启校正。自动（魔棒）在胶片可证实的每处漏光上放置形状：受光片边延续进画面处放置边缘，直线漏光放置条带。止于画框线的光晕视为边缘雾翳或边码，自动不处理。
- 从胶卷（胶片图标）：选中其他帧时，将本帧的漏光带到每一帧，每帧自行读取强度和颜色；未选中时，选中自动检测找到漏光的帧。
- 胶片 Dmax（关闭，或 0.05–4.0 D）：胶片的最大密度，用于高密度端已饱和的胶片。
- 恢复色层：用仍保留画面的其他层重建被漏光推到最大密度的色层。
- 颗粒与反差只作用于去除漏光处：颗粒平复被拉伸的颗粒，反差恢复被压平的反差。
- 条带：沿漏光最强的线拖动，再把每条虚线边缘拖到漏光消失处。
- 边缘：沿漏光进入的一侧拖动，线会吸附到该侧。裁切包含帧间受光间隙时，边缘会沿整侧清除该间隙。
- 光斑：在圆形漏光上拖出椭圆。
- 涂刷：在没有直线或中心的漏光上涂刷，范围要比漏光更宽。
- 所选漏光：强度（0–400%）决定去除多少漏光；衰减决定条带、光斑或涂刷区域向边缘的衰减方式；颜色决定颜色来源（自动、背面表示穿过片基的光、正面表示从乳剂面射入的光）；颜色微调增减去除其主导颜色。黑白胶片隐藏颜色与颜色微调。
- 显示烧透（火焰）标出漏光在所有层中烧透的胶片。

## 修复：灰尘、毛发、划痕

去除灰尘、毛发和划痕。每处修复都用周围干净的胶片重建。

- **叠加显示**：**已标记**显示除尘找到的位置，**红外**显示扫描的红外通道。
- **光学除尘**：自动查找灰尘和毛发。**尘点阈值**和**毛发阈值**：数值越低检出越多，但可能误删真实细节；1 为关闭。**尺寸**：要去除的最大灰尘。要保护某区域，在其上右键拖动，或右键点击某个痕迹；光标按钮可跳过右键菜单。
- **红外除尘**（带红外通道的扫描）：在画面不可见的红外中查找灰尘。**红外阈值**：数值越低检出越多。**方法**：**OpenICE** 比 **NegPy** 保留更多细节，但验证较少。黑白和柯达克罗姆胶片会被跳过，因为它们的画面在红外中也可见。红外通道来自 4 通道 TIFF 和 DNG 扫描，或扫描旁的 `_IR.tif` 文件。
- **修复**：点击或涂抹灰尘。只修复明显的痕迹，所以可以涂得宽一些。
- **划痕**：沿划痕或毛发点击各点，然后按 Enter。
- **直线**：在一条长直划痕上点击一次，NegPy 会找到并修复整条线。**直线灵敏度**：数值越低能找到越淡的线。
- **画笔大小**：也可在画面上按 `Alt`+滚轮调整。
- **仿制**：把别处的胶片复制到修复工具无法处理的瑕疵上。第一次点击（或按住 `Alt` 点击）选择来源，然后涂抹。**设置源点**重新选择来源。**匹配影调**让复制区域采用瑕疵周围的亮度和颜色。**强度**决定覆盖程度，**羽化**决定边缘柔和程度。
- **撤销上一步**和**全部清除**移除手动修复；在画面上右键点击某处修复可将其删除。

## 修饰：暗角、片夹、边框

照片的呈现方式。每种效果的其他滑块在其第一个滑块不为 0 时显示。

- **暗角**：**加光**让四周变暗（正）或变亮（负）。**尺寸**决定作用范围，**圆度**从圆形（0）到照片形状（1）。
- **锉宽片夹**：**宽度**在画面周围画出粗糙的黑框，就像暗房中被锉宽的底片夹。**粗糙度**、**眩光**（框外的灰色光晕）和**圆角**调整其形状。
- **边框**：**宽度**为照片加上卡纸边。**底边加宽**像装裱卡纸一样让底边更宽。**颜色**：**相纸白**与相纸一致，**自定义**使用你选择的颜色。

## 基础设置

胶片类型和扫描方式。这些选择决定显示哪些卡片和控件。

- **彩色 / 黑白 / 反转片**：彩色负片（C-41）、黑白负片或反转片（E-6 等）。
- **正片**（仅反转片）：用于已经是正像的文件，如扫描的照片或其他应用导出的图像。NegPy 会跳过反转和测光。
- **相机 / 胶片扫描仪**：用什么扫描。选择之前由 NegPy 从每个文件读取（相机 RAW 即为相机）。你的选择适用于所有帧，并决定扫描选项卡的扫描仪。
- **白光 / 窄带 RGB**（黑白除外）：负片背后的光源。白光是灯箱或 LED 面板；窄带是发出纯红、绿、蓝光的光源，如 Scanlight。

扫描选择是整个应用的一项设置。它决定 RAW 文件的解码方式和使用的数字印相材料：

| 扫描设备 | 光源 | 解码 | 印相材料 |
| --- | --- | --- | --- |
| 相机 | 白光 | 相机白平衡 | 数字 (Adobe RGB) |
| 相机 | 窄带 | 线性 RAW | 数字 (Pakon Minilab) |
| 胶片扫描仪 | 白光 | 线性 RAW | 数字 (Adobe RGB) |
| 胶片扫描仪 | 窄带 | 线性 RAW | 数字 (Pakon Minilab) |

相机会显示 RAW 解码和光学卡片。使用窄带光的相机还会显示三色扫描和校准卡片。更改后所有打开的帧都会更新（Ctrl+Z 可逐帧撤销），但你自己选择的印相材料保持不变。相机扫描按每帧的光源设置解码和印相材料。

## 画面组合

如何把文件变成帧。每卷各自保留这些设置。

### 三色扫描

用于对每帧拍摄红、绿、蓝三张的窄带光相机。

- **三色扫描模式**：把三张合成一张彩色帧。按拍摄时间（或文件名）分组，因此请连续拍摄每帧的三张。无法分组的照片保持独立。
- **编辑三色组…**：手动选择当前帧的三张照片。**对齐通道**会对齐它们以去除彩边。
- **将画面合并为 TIFF 负片…**（右键）：把三色组或拼接连同编辑保存为一个 TIFF，放在第一个源文件旁。还有把源文件移到废纸篓的选项。

### 半格

- **调整…**：拖动白色框裁切，拖动橙色线设置分割位置。**拆分方向**和**切割厚度**设定间隙，**自动检测**重新查找，**应用**保存到此帧、所选帧或所有帧。

右键点击一半可选择**调整此画面的拆分…**和**将拆分恢复为胶卷默认值**。关闭半格后，已编辑的两半会作为**双联画**并排保留；再次开启即可编辑。

## 校准：扫描设备带来的颜色

校正来自光源、相机和胶片的颜色误差。

**单次窄带校准**（窄带光相机，线性 RAW）：去除传感器通道之间串扰的颜色。更改后请重新运行**胶卷分析**。

- **配置**：传感器配置。自建的 `.toml` 配置放在 `<Documents>/NegPy/sensor/`。
- **方法**：**双尺度**（默认）去除串色，并防止非常浓的颜色出现斑点。**线性**最精确，但浓烈的颜色可能出现斑点。**密度**没有斑点，但浓烈的颜色略显暗淡。
- **校准**：用三张只拍光源的照片（红、绿、蓝）制作配置，来源可以是文件或联机相机（见 CAMERA_SCANNING.md）。

**串扰**（彩色胶片）：胶片染料、光源和传感器会让颜色略微混合，矩阵把它们重新分开。更改后请重新运行**胶卷分析**。

- **矩阵**：此胶片类型的矩阵。标有 *(approx)* 的矩阵来自胶片数据表，只是起点。自建的 `.toml` 放在 `<Documents>/NegPy/crosstalk/`（见 CROSSTALK.md）。滑块按钮打开编辑器，**+** 新建矩阵。NegPy 不附带反转片矩阵。
- **强度**：应用矩阵的程度。
- 色块按钮打开**从色卡测量**（彩色负片）：它用胶片拍摄的 ColorChecker 24 或 SpyderCheckr 24 测量矩阵。把四个点拖到四角的色块上。

**色相微调**（窄带光相机）：针对让黄色偏橙、绿色偏橄榄色的光源，在色轮上旋转所有颜色。白光下保持 0。它也适用于不能使用传感器配置的反转片。

## 测光：从负片到正片

为了把负片变成正片，NegPy 会测量最暗和最亮的部分（黑点和白点）以及胶片的颜色。这些控件决定测量什么。

- **重新分析此帧**：按当前裁切重新测量此帧。
- **绘制区域**：画出一个区域，NegPy 只测量该区域。在区域内双击确认；**×** 清除。
- **片基**：点击帧之间的透明胶片，为分析显示设置整卷的片基。**×** 清除。
- **分析缓冲区**：测量时忽略画面四周的一圈，使胶片边缘和片夹不被计入。
- **截断**：照片中纯黑或纯白的比例。
- **锁定范围**：即使裁切或胶卷分析改变，也保持此帧的黑点和白点。
- **亮度范围截断**（折叠区）：黑白点设定的松紧。正值反差更大，适合厚密或有灰雾的负片；负值保留更多暗部和高光细节。
- **颜色截断**（折叠区）：色彩平衡设定的强弱。
- **白点** / **黑点**（折叠区）：移动测得的白点和黑点。白点为正时照片变亮，黑点为正时黑色变浅。**R / G / B** 只移动一种颜色。

**反转片**不需要反转，色调控件直接调整画面。自动密度和自动反差一开始是关闭的；褪色的反转片可以打开它们。用 Lightroom 的说法：曝光对应印相密度（越低越亮），对比度对应 ISO-R 反差等级，阴影和高光对应暗部密度和高光密度。

## 胶卷分析

一次测量整卷并共享结果，让同一卷胶片的各帧印出来一致。

- **重新分析**：测量所有已载入的帧（场景帧和锁定帧除外），并把平均值保存为整卷基准。与其他帧差异很大的帧保留自己的值。它会先裁切等待自动裁切的帧。
- **使用此帧**：把此帧的测量值作为整卷基准。
- **使用平均值**：**亮度**使用整卷的黑点和白点，**颜色**使用整卷的色彩平衡，**色偏**（彩色负片）为去色偏使用整卷的灰平衡。亮度和颜色都开启时整卷印出来一致；都关闭时每帧单独测量。
- **基准**：显示基准的来源（整卷、场景或帧）。没有基准或基准过期时会提示。
- **胶卷**：选择另一卷保存的基准。打勾的胶卷有基准。
- **场景**：拥有自己基准的一组帧，如同一光线下的同一主体。**分析**测量该场景，**选择**选中它的帧，**删除**移除该分组。

## RAW 解码

把相机 RAW 文件变成像素的方式。使用相机时显示。

- **相机白平衡 / 线性 RAW**：相机白平衡使用相机的白平衡。线性 RAW 以中性方式解码，适合窄带光。设置会自动选择。
- **预览** / **导出**：去马赛克方法，补出每个传感器像素看不到的颜色。**自动**在屏幕上更快，导出时使用 **AHD**。**VNG** 平滑，**PPG** 快速。**DCB** 和 **DHT** 保留更多细节，但可能把颗粒变成花纹。**AAHD** 让边缘更柔和。只列出你的 LibRaw 版本中有的方法。
- **恢复**（反转片）：重建相机 RAW 中过曝的高光。**混合**适合太阳和天空。**重建**更强，但颜色可能出错。

## 光学

- **复制 / 垃圾桶**：复制或删除所选项。内置项无法删除。

## 预设

已保存的元数据组合，如一套相机、镜头和胶片。保存在 `~/NegPy/presets/metadata/`。

- **应用到此画面**：把预设的字段写入此帧，其他字段不变。
- **+**：以名称保存当前帧的元数据。
- **⋮** 或右键点击预设：应用、复制、编辑或删除。
- **详细信息**：编辑预设的字段。**备注**可自由填写。

胶片型号会同时设定画幅，因此请在胶片之后再设定 `6×7` 这样的画幅。

## 预设

已保存的导出配方：格式、尺寸、色彩、文件夹和文件名。打开需要的预设后，**导出预设**会按每个预设各导出一次每一帧。**管理**用于编辑。线性输出不支持预设。

## 随导出

与照片一起生成的附加文件。每项左侧是开关，右侧是一次性操作。

- **印相笔记**：标有局部加减光和印相设置的帧副本，就像暗房印相师的记录。**预览**显示它（`Shift+N`）；**导出笔记**保存它。
- **自动密度 / 反差**：**导出时固化**会固定每个导出帧的自动亮度和反差，使其以后不再变化。**固化到胶卷**立即对所有可见帧执行。
- **编辑附属文件**：**导出时保存**在每个源文件旁写入含编辑内容的 `.negpy` 文件。**导出附属文件**为所有可见帧写入。右键点击某帧 → **从附属文件加载编辑…**可读回。

## 接触印相

位于**随导出**选项卡。接触印相像暗房印样一样，把整卷以胶片条的形式排在一张纸上。

- **路径**：印样的保存文件夹。留空则使用导出文件夹。
- **接触印相…**：打开印样。拖动纸张边缘可改变大小。
- **胶片画幅**：35mm、35mm 半格或 120（120 还需设置**画面尺寸**）。
- **相纸**、**宽度**、**高度**和 **DPI**：印样的尺寸和分辨率。默认相纸可容纳 36 张一卷。
- **顺序**：按日期，或按场景（每个场景另起一条或一行）。
- **印相**：**按编辑结果**，或**直接样片**：整卷以同一曝光和常规反差印出，便于看出哪些底片偏薄或偏厚。
- **选择画面**：点击某帧可将其排除或放回。拒绝的帧一开始就被排除。
- **边缘印相**：胶片边缘的厂商标记，如胶片名称和帧编号。
- **胶卷标签**：在胶片条上方印上胶卷名称、胶片、相机和日期。
- **白纸**：印在白底上，节省家用打印机的墨水。
- **胶片边缘**：关闭时画面正向、按各自形状排成多行，与灯箱一致。此时印样没有齿孔，也没有**边缘印相**。

印样保存为 `contact_sheet.jpg`（长卷为 `contact_sheet_1of2.jpg` 等）。

## 软打样

**打样**选项卡在屏幕上显示用指定打印机和纸张打印后的样子。它只改变预览，不影响导出。纸张无法呈现像屏幕那样明亮的颜色，所以正确的打样看起来会更暗淡。

- **屏幕软打样**（`Shift+P`）：开启或关闭打样。
- **预设**：已保存的打印机和纸张设置。
- **配置**：打印机或纸张配置。选择之前跟随导出配置。
- **意图**：**相对比色**让可打印的颜色保持准确，其余截断。**可感知**压缩所有颜色，适合色彩丰富的照片。**饱和度**用于图表和图形。
- **黑点补偿**：把最暗的色调映射到纸张的黑色。
- **模拟纸白**和**模拟墨黑**：显示纸张真实的白色和黑色。
- **色域警告**：把打印机无法印出的颜色显示为灰色。
- **显示**：自动找到的显示器配置。

## 设备

- **后端**：**SANE**（Linux 和 macOS）、**Nikon Coolscan (nkscan)** 或 **pyOpticfilm (Plustek)**。控件随扫描仪报告的功能变化。
- **设备**：扫描仪；箭头刷新列表。弹出菜单有**立即弹出**，送片器上还有**完成后弹出**，批量扫描后退回胶片条。
- **调试日志**（Coolscan）：在 NegPy 文件夹中写入 `nkscan.log`。报告问题时设为 **Trace**，重现问题后附上该文件。

扫描期间 NegPy 会阻止 macOS 和 Windows 休眠。在 Linux 上，扫描长卷前请关闭自动挂起。

**Plustek**：支持 OpticFilm 8200i SE、8100 V2、8300i SE 和 7600i v1；其他型号可试用 SANE。在 Windows 上请先设置 USB 驱动（[PLUSTEK_WINDOWS.md](PLUSTEK_WINDOWS.md)）。**Coolscan**：不需要 SANE。在 Linux 上 USB 需要为厂商 `04b0` 添加 udev 规则。

<!-- panel:scan_quality src:f47a659a -->
## 胶片与质量

- **胶片**：彩色负片、黑白负片、反转片或柯达克罗姆。它决定画幅检测、测光以及是否提供红外。
- **胶片画幅**：帧长度（135、66、645 等）。片夹能确定时可用**自动**。
- **分辨率**和**位深**：扫描的 dpi 和每通道位数。
- **扫描模式**（Plustek）：**多次扫描**平均多次扫描以降低噪点；**自适应多重曝光**结合短曝光和长曝光以扩大范围。
- **采样次数**（Coolscan）：每行读取多次，减少暗部噪点。速度更慢。
- **红外**：**IR** 扫描一个红外通道，用于修复卡片的除尘。**ICE**（Coolscan）改为在扫描仪内除尘。没有 ICE 的扫描仪只显示一个 **IR** 开关。不适用于黑白和柯达克罗姆。
- **超精细**（Coolscan）：每次只扫描一行。速度更慢。
- **自动对焦**、**自动曝光**和**曝光**：扫描前扫描仪的对焦和曝光。

<!-- panel:scan_framing src:945dad86 -->
## 取景

- **画面**：`1-6`、`1,2,5`，留空表示全部。胶片条预览会自动填写。
- **预览胶片条…**（送片器）：预览每一帧，用于定位和选择帧。**预览…**（手动片夹）：设置一个裁切窗口。**清除**重置。**检测帧**在胶片移动后重新查找帧。
- **单帧测光…**（Coolscan）：在一帧上测量曝光，并用于之后的每次扫描，让整卷一致。**解锁**结束。每卷请重新测光。
- **预扫描…**（Plustek）：快速的整体预览。拖出裁切后，下次扫描只读取该区域。

<!-- panel:scan_camera src:6032ab5d -->
## 相机

用翻拍架上的相机扫描，通过 USB 以 **PC 遥控**模式连接（macOS 和 Linux，需要 `python-gphoto2`）。有 NegPy **Scanlight** 时还会控制光源。设置方法见 CAMERA_SCANNING.md。

- **相机** / **光源**：连接状态。光源发热时变为琥珀色。在 Linux 上，使用 Scanlight 需要把你的用户加入 `dialout` 组。
- **实时取景**：相机的实时画面。点击放置对焦放大镜，对焦直到**对焦测量**显示**达到峰值**。ISO、快门和光圈可在这里或相机上设置。
- **直方图**和**斑马纹**：帧的直方图，以及即将截断部分的条纹，颜色为色觉设置的截断配色。
- **测光**：设置快门，让不能截断的最亮部分（负片的透明胶片、反转片的高光）刚好低于截断。
- **扫描**拍摄下一帧并导入；**重拍**（重做箭头）重拍上一帧。在实时取景窗口中，`Space` 或 `S` 扫描，`R` 重拍。使用 Scanlight 时，**R**、**G**、**B** 和**红外** 选择重拍哪些曝光。
- **拍摄延迟**：在第一次曝光前等待，让晃动的台面稳定。
- **保持灯亮**（灯泡）：每次扫描后让 Scanlight 保持点亮，便于为下一张取景。

<!-- panel:scan_light src:0fbabbe4 -->
## 预设

连接 Scanlight 时显示。预设保存适合某类胶片的光源强度和相机曝光。

- **预设**：每次扫描的光源和曝光。**+** 有三种添加方式：
    - **内置预设**：无需校准即可使用：**白光**、**白光 + IR**、**三色扫描**和**三色扫描 + IR**。它们使用由测光设置的相机曝光。白光需要带白光 LED 的 Scanlight（v4、Big Scanlight）。
    - **在片基上校准…**：把矩形放在透明胶片上运行，NegPy 会求出光源强度和快门。
    - **手动设置**：自己设置滑块，然后保存为预设。
- **红色**、**绿色**、**蓝色**、**白色**：光源强度（0 到 255）。**关灯**关闭光源。
- **采集模式**：**三色组**每种颜色各拍一次再合并；**单次采集**三色同时点亮拍一次。
- **创建传感器配置**（单次采集）：同时为此预设保存传感器配置（见校准，§10.3）。
- **ISO**、**快门**、**光圈**：预设的曝光。更改会保持到你再次选择该预设。仪表按钮用于测光。
- **IR 快门**和**红外**（带红外 LED 的光源）：每次扫描追加一次红外曝光用于除尘，保存为 `_IR` 文件。需要能拍红外的相机（全光谱或改装）和手动对焦。仅限彩色胶片。
- **通道延时**：为需要的相机在红、绿、蓝曝光之间暂停。

<!-- panel:scan_output src:3015443a -->
## 输出

两种扫描仪共用。

- **文件夹**：扫描的保存位置。
- **扫描为胶卷**：把文件夹作为胶卷打开，帧保存后即载入。
- **文件夹作为胶卷**：扫描保存到文件夹本身。关闭时写入**胶卷**子文件夹，新的胶卷名称会开始新的一卷。胶卷旁的 **+** 跳到下一个名称（`Roll001` 到 `Roll002`）。
- **格式**和**文件名**（胶片扫描仪）：TIFF，或用于黑白的 TIFF（单色），以及文件名规则（`{{ date }}`、`{{ seq }}`）。

## 胶片条预览

扫描前显示整条胶片，用于定位和选择帧。**应用取景范围**保留取景，**扫描**开始扫描。**停止预览**提前结束预览。

- **裁切**：在帧上拖动。**清除裁切**移除所有裁切。
- **偏移**：沿胶片移动所有帧，使其对准画面。白框是 NegPy 找到的帧。
- **漂移**：逐帧增大的偏移。
- 每个缩略图下方的滑块只移动该帧。
- **尺寸**设置缩略图大小；**全部**、**无**和每帧的开关选择帧。**预览帧**重新扫描一帧。

## 偏好设置

- 语言默认跟随系统，可选英文、简体中文、日文或韩文，重启后生效；缺失的面板帮助回退英文。
- 界面缩放 80%–120%，重启生效；画布背景选择黑、深灰、中灰或白；沉浸画布使工具栏覆盖图像；保留缩放与反向滚轮控制切换和缩放行为。
- 自定义快捷键、编辑工具栏与重置面板布局管理操作入口，色觉选择用于区分各类标记的配色。
- GPU 加速失败时回退 CPU；多核 CPU 为实验设置。语义搜索首次下载模型。预览尺寸、缓存、高质量缓冲与纹理上限控制内存，标明启动设置的行需重启。
- 沿用设置和持久设置控制新文件继承；管理数据库可查看占用或清除编辑、图库与缓存。override.toml 的指定项优先于偏好设置。
